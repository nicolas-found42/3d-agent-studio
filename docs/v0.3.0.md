# v0.3.0 migration

Provide `prompt` in the brief and a Blender Python script defining `build(kit)` when you call `draft` or `studio_draft`. The fixed Gravity Conveyor and Orbit Bloom presets and their `template`, `primary`, and `accent` brief fields have been removed. To preserve a palette or composition, provide it in the prompt or ingest a reference.

- Use `studio_ingest` to attach references and `studio_examples` to find reusable techniques. The former presets are absent from the example search.
- Use `studio_probe` to check three stills and estimated render time before starting the full draft. After a revision, use the new job's review hashes when finalizing.
- Read `probe.jpg` and, for jobs with visual references, `references.jpg`. The draft still has `timeline.jpg`, `angles.jpg`, and `seam.jpg` for loops. The old `sections.jpg` board was removed.
- Keep earlier jobs for their media and editable Blender files. To use the current render pipeline, start a new job with the source prompt, references, and script.

For command signatures, see the [operations reference](../skills/3d-agent-studio/references/operations.md). For agent installs, see the [marketplace guide](marketplace.md).
